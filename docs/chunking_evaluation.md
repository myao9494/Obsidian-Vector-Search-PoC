## 2. チャンキング最適化のポイント

| 改善項目 | 以前の実装 (Baseline) | 最適化後 (Optimized) |
|---|---|---|
| **見出し階層 (Breadcrumbs)** | チャンク単体テキストのみ（コンテキスト欠落） | `# タイトル > ## セクション > ### サブセクション` を先頭に自動付加 |
| **ファイル名・タイトル** | 先頭H1で上書き（ファイル名欠落） | ファイル名（stem）を第一階層として確実に保持 |
| **タグ (Frontmatter & In-body)** | Frontmatterごと除外 | `tags:` および `#tag` を抽出し `[Tags: #A #B]` として統合 |
| **Obsidian 記法** | wikilink がブラケットのまま残存 | `[[ノート名\|表示名]]` を自然言語プレーンテキストに展開 |
| **短文ノート救済** | 30文字未満を空判定して除外 | タイトル・タグ・本文を結合して確実に1チャンクとして保持 |
| **構造保持分割** | 固定文字数での強制的切断 | 見出し・空行・リスト（箇条書き）境界を尊重した500文字分割 |
